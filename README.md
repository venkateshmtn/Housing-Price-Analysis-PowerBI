Housing Price Analysis – Power BI Dashboard

Project Overview

This project analyzes housing market data to identify pricing trends, location-based price variations, and key factors affecting property valuation.
The dashboard provides interactive insights for real estate decision-making.

Tools & Technologies: SQL – Data extraction & transformation, Python – Data cleaning & preprocessing, Power BI – Data modeling, DAX, and visualization, Excel/CSV – Dataset

Key Insights: Average house price by location, Price distribution by property type, Correlation between area and price, Year-over-year price trends, Top high-value locations

Dashboard Features: Interactive slicers (Location, Property Type, Year), KPI cards (Avg Price, Total Listings, Max Price), Drill-through capability, Trend analysis charts

Business Impact: Helps identify profitable investment locations, Detects pricing trends over time, Supports data-driven real estate decisions
